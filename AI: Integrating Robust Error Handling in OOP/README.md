# Task 0: AI: C Preprocessor Co-Pilot

## Scenario
**Scenario A:** Arithmetic Macro Safety Inspection

## Overview
This task demonstrates using AI to identify and fix critical bugs in C preprocessor macros before compilation.

## Files
- `flawed_macro.c` - Initial unsafe MAX macro with operator precedence and side-effect vulnerabilities
- `safe_macro.c` - Production-ready macro generated by AI with header guards, DEBUG/RELEASE modes, and type safety checks

## Flawed Macro Issues
The original `#define MAX(a, b) a > b ? a : b` has two critical bugs:

1. **Double Evaluation (Side Effects):** Calling `MAX(x++, y++)` increments both arguments multiple times
2. **Operator Precedence:** `MAX(2+3, 4+5)` evaluates incorrectly due to missing parentheses

## AI-Generated Solution
The safe version includes:
- Header guards to prevent multiple inclusion
- Type safety checks using `sizeof` tricks
- GCC statement expressions (`typeof`) for single evaluation
- DEBUG mode with `__FILE__` and `__LINE__` tracing
- RELEASE mode optimized with zero overhead

## Key Improvements
- Arguments evaluated exactly once (eliminates side effects)
- Type compatibility validation at compile-time
- Conditional compilation for debug vs. release builds
- Production-grade safety without performance cost

## Tools
- Claude, Gemini, and ChatGPT as Safety Inspector and Code Generator
- Prompts included specific bug classes and three distinct requirements

## Reflection
Using AI to inspect preprocessor code before compilation catches subtle bugs that are hard to spot manually, like side-effect issues and operator precedence problems. This saves debugging time and prevents runtime crashes. AI can also rapidly generate safe, production-ready macro scaffolding with proper guards and conditional logic.
